        The dataset
        
150 flowers, 4 measurements, 3 species

        
Ronald Fisher's 1936 iris data — the "hello world" of pattern recognition. The notebook
           injects synthetic missing values, then repairs them with column means before training.

        REST API & deployment
        
Everything is programmable

        
The UI above is a thin skin over two JSON endpoints. Point any HTTP client at this
           deployment — or clone the repo and host your own on Render.

      


      

        

          
Endpoints

          
    
            
  • GET/api/healthService + model status
    • 
            
  • GET/api/model-infoFeatures, classes, accuracy
    • 
            
  • POST/api/predictClassify one flower
    • 
            
  • POST/predictLegacy alias — same behaviour
    • 
          

          
Example request

          

            
            
curl -X POST https://YOUR-APP.onrender.com/api/predict \
  -H "Content-Type: application/json" \
  -d '{"sepal_length": 5.1,
       "sepal_width": 3.5,
       "petal_length": 1.4,
       "petal_width": 0.2}'

          

          
Example response

          

            
{
  "prediction": "setosa",
  "confidence": 0.9647,
  "confidence_scores": {
    "setosa": 0.9647,
    "versicolor": 0.0321,
    "virginica": 0.0032
  },
  "latency_ms": 1.42
}
